# Plan + Routine editor

D02, Plan, Exercise detail. FR-05, FR-02, AT-03. Demo account, routine at version N.

## 1. Wi-Fi
1. Open Plan. Tap Improve on a goal. Open Progress: same level shows.
2. Tap Edit routine. Header says "Draft of vN". Change reps on one exercise.
3. Banner says "Saving creates version N+1". "What changed from vN" and the estimate both update.
4. Tap "Save as vN+1". Toast: "Saved as vN+1 · saved on this device".
5. Open Train. It shows the new version. Progress and Recent still list your old sessions, unchanged.
6. Edit again. Tap "Group with next" on two exercises. Set rounds and rests. Then Ungroup.
7. Use up and down on one exercise. It moves one place.
8. Tap "Discard draft". Plan still shows vN+1.
9. Open an exercise. Badge reads Reviewed, Yours or Not reviewed.

## 2. Airplane mode
10. Airplane on. Edit, Save. Plan row says "Saved on this device".
11. Start a session from that version.
12. Airplane off. Version syncs first, then the session, each once.
13. Save the routine on a second device first, then reconnect this one. The row says "Didn't sync" with "Keep editing" and "Discard this save". Keep editing opens the editor on the newest version with your changes.

## 3. Lock
14. Mid-edit, lock two minutes, unlock. Draft is still there.

## 4. Kill the tab
15. Close the tab, reopen Plan. All versions are listed, no duplicates.

## 5. 320 px
16. Zoom to 320 px. Plan and editor: no sideways scroll. On a desktop 1024 or wider, two columns.

## 6. Night Gym
17. Dark mode. Plan, editor and exercise detail follow.
