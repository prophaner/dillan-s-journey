# Progress S08

S08. FR-10. Demo account with goals; weight and height set.

## 1. Wi-Fi
1. Open Progress. Goal cards with no data say "Not yet known", not zero.
2. Tap Body, then "Add a measurement". Pick weight, type a value, choose the unit, Save.
3. Add another. The sheet shows a "Last:" line with your first value.
4. Add an arm measurement with Left. Add another with Right. Two separate cards.
5. Once weight and height exist, a BMI card appears, labelled "derived".
6. Go to Goals. The "Steady weeks" card shows pips for your real weeks only.
7. Switch Goals, Body, History. Each filter shows its own list.

## 2. Airplane mode
8. Airplane on. Add a weight. Header says "Saved on this device".
9. Airplane off. It turns "Synced", once.
10. Body shows that weight one time, no duplicate.

## 3. Lock
11. Open the Add sheet, type a value, lock two minutes, unlock. Value still there.

## 4. Kill the tab
12. Close the tab, reopen Progress. Every measurement still listed.

## 5. 320 px
13. Zoom to 320 px. Goal cards, Add sheet, Steady weeks pips: no sideways scroll.

## 6. Night Gym
14. Dark mode. Progress, the sheet and the BMI card follow.
