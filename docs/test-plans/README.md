# On-phone checklists

One file per accepted slice, written by the phone-tester agent. Run them in this order on an iPhone
(Safari) and an Android phone (Chrome); fill in the result block at the end of each file. Steps that
need the service worker say so and work only on the published app, not the Lovable preview.

| Order | File | Steps | Covers |
|---|---|---|---|
| 1 | workout-s16-s04-s05-s07.md | 21 | Start, log sets, undo, rest, lock, Something feels off, finish |
| 2 | edits-superset-s04-s06.md | 19 | Edit a done set, swap, supersets, discard |
| 3 | something-feels-off-s11.md | 16 | Stop or end with a dated note |
| 4 | today-s01-s02-d01.md | 16 | Full / Short / Priority-only, week strip, resume, desktop |
| 5 | progress-s08.md | 14 | Goal cards, Steady weeks, measurements, BMI |
| 6 | plan-routine-editor.md | 17 | Goal levels, edit routine, new version, supersets, failed save |
| 7 | states-s20-s21-conflicts.md | 16 | Your data sheet, conflicts, offline, update banner, storage |
| 8 | profile-settings.md | 18 | Equipment, limitations, availability, units, time zone, Settings |

When a file's result block is filled in, tell the lead; the docs-writer copies "Verified on phone:
yes/no" to roadmap.md and docs/CHANGELOG.md. Known issues to expect are listed at the end of
docs/user-manual.md and in the latest CHANGELOG entry.
